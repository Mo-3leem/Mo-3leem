## 🚀 Featured Projects

### 1. Event Ticket & Payment Orchestration Platform

**Java · Spring Boot · Spring Security · PostgreSQL · Flyway · Maven · Docker**

A backend project focused on event ticketing, secure booking workflows, and transaction safety.

- Implemented JWT-based authentication and password hashing.
- Built REST APIs for event catalog and seat reservation workflows.
- Used PostgreSQL row-level locking to prevent conflicting seat reservations.
- Implemented booking hold expiration and database migrations.
- Added integration tests for authentication, concurrency, and expiration.

🔗 [View Repository](https://github.com/Mo-3leem/event-ticket-payment-orchestration-platform-)

### 2. Wallet & Transfers API

**Node.js · Express.js · PostgreSQL · Docker · Jest**

A financial backend focused on reliable money transfers and database consistency.

- Designed atomic transfer workflows and an append-only transaction ledger.
- Applied ACID transactions and row-level locking.
- Implemented idempotent APIs to help prevent duplicate operations.
- Added database indexes and automated integration tests.

🔗 [View Repository](https://github.com/Mo-3leem/wallet-transfers-api)

### 3. Interactive Compiler Platform

**Node.js · Express.js · WebSockets · MongoDB · Docker**

An online code execution platform supporting multiple programming languages.

- Supported Python, JavaScript, C++, Java, and Go execution.
- Implemented real-time execution output using WebSockets.
- Added CPU, memory, process, timeout, and network restrictions to execution containers.
- Built authentication, project management, and execution history features.

🔗 [View Repository]([https://github.com/Mo-3leem?tab=repositories](https://github.com/Mo-3leem/interactive-compiler-platform.git))
